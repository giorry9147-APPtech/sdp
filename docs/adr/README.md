## Nieuwe ADR toevoegen

Format: `NNNN-korte-naam.md` met secties:
- Status (voorgesteld/geaccepteerd/vervangen-door-NNNN/afgewezen)
- Datum
- Context
- Beslissing
- Gevolgen
- (optioneel) Alternatieven overwogen
